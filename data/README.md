# Data

The raw dataset used in this project is not committed to this repository.

**Source:** [Healthcare Dataset by prasad22 on Kaggle](https://www.kaggle.com/datasets/prasad22/healthcare-dataset)

To reproduce this project:
1. Download the CSV from the link above.
2. Open `notebooks/data_profiling_and_cleaning.ipynb` in Google Colab.
3. Upload the CSV when prompted and run all cells — this reproduces the profiling, cleaning, and database load steps described in the main README.
